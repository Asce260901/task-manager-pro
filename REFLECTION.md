## What Are the Top 3 Things You Learned This Semester?

**1. Component-Based Thinking and Modular Code Design**

One of the most important concepts I internalized this semester was how to think in components. When I built Task Manager Pro using React and Next.js, I had to break the entire application into small, focused pieces — a form for adding tasks, a card for displaying them, a bar for filtering, and a panel for statistics. At first this felt like extra work, but I quickly saw how much easier it made debugging, testing, and adding new features. This modular mindset now applies to everything I write, not just React.

**2. How Databases Power Real Business Applications**

Working with SQLite in the data explorer lab was a turning point for me. I had always understood databases abstractly, but actually writing SQL queries to join tables, aggregate results, and extract insights from a real dataset made it click. I saw firsthand how the same data can tell completely different stories depending on how you query it. This experience made me much more confident talking about data and working with relational systems, which are foundational to almost every business application.

**3. The Importance of Professional Code Presentation**

This semester taught me that code alone is not enough — how you present and document your work matters just as much. I learned to write meaningful README files, use consistent naming conventions, commit with descriptive messages, and organize project folders in a logical way. These habits make code easier for others (and future me) to understand, and they demonstrate professionalism that employers actually look for.

## Which Assignment or Project Are You Most Proud Of?

I am most proud of **Task Manager Pro**. It is the most complete and polished application I have built. It goes beyond simple CRUD operations — it includes priority levels, due dates, inline editing, live statistics, filter and search functionality, and a dark/light theme toggle. What I am proudest of is not just what it does, but how it is built. The code is organized into reusable components with clear responsibilities, and the user experience feels smooth and intentional. When I look at this project, I see real growth in how I think about software.

## Which Project Challenged You the Most, and Why?

The **SQLite Data Explorer** lab challenged me the most. I had limited experience with databases before this course, and the jump from writing basic SELECT statements to writing multi-table joins with aggregations was steep. I also had to learn a new tool (VS Code's SQLite extension) and figure out how to interpret query results in a meaningful way. What made it harder was that there was no visual feedback loop like in a UI project — if my query was wrong, I just got incorrect data. It forced me to slow down, think carefully about data relationships, and test each part of my query before combining them. That struggle made the eventual results feel very rewarding.

## How Has Your Understanding of Business Application Development Changed?

Before this course, I thought of business applications as static tools — spreadsheets, forms, and dashboards that just display information. Now I see them as dynamic systems that model real business processes: orders flowing through a pipeline, customers being tracked across interactions, tasks moving through stages of completion. I understand that every design decision in a business app — how data is structured, how the interface responds, how errors are handled — has a direct impact on how useful the tool is in a real work environment. I approach development now with a clearer sense of the problem I am solving and who I am solving it for.
